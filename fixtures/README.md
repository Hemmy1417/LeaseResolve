# Fixtures

`photos/` holds the room photographs the live proofs file. They are rendered by `make_photos.py`, not photographed: plain drawings of a wall, a basin and kitchen cupboards, each pair differing in the one way its case turns on (holes and a stain; a chip already there at move-in; light scuffs). Fixed seeds, so re-running the script reproduces the same bytes and the digests in the proof log stay checkable.
